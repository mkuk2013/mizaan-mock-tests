# Mizaan Mock Tests

**Mizaan Testing Service — Sindh Academic Talent Challenge 2026 · Phase I**

Online mock-test PWA for students of **Class 8, 9, 10 and 12**, built strictly on the
**Sindh Textbook Board (STBB), Jamshoro** syllabus.

## What's inside

- 4 class sections — Class 8, 9, 10, 12
- 5 mock tests per class, **100 MCQs per test** (2,000 questions total)
- Content subjects (Math, Science, Physics, Chemistry, Biology, Computer) are
  **bilingual — English + Sindhi** (language choice: Both / Only English / Only Sindhi),
  because Sindh government schools teach in Sindhi medium and private schools in English medium
- 100-minute timer, instant results, full answer review with filters
- Each class is **password protected** — students contact on WhatsApp to get the password
- Installable as a PWA (Install App button on the page)

## Run / Deploy

Single static file — just serve `index.html`:

- **Netlify:** drag this folder onto Netlify, or connect this repo (publish directory: `.`)
- Any static host works the same way.
